Overview

스마트홈 스위치의 사용자 경험과 GUI를 설계했습니다.

기존 아파트에 설치되는 스마트 스위치는 하드웨어 디자인과 GUI 모두 오래된 인터페이스를 유지하고 있어 공간의 미관과 사용자 경험을 저해하는 문제가 있었습니다.
본 프로젝트는 거실에 설치되는 5인치 스마트 홈 스위치를 대상으로 최신 UI 트렌드를 반영하고, 다양한 홈 IoT 기능을 직관적으로 제어할 수 있는 인터페이스를 설계했습니다.
단순한 기능 추가보다 누구나 쉽게 사용할 수 있는 정보 구조와 일관된 인터랙션 경험을 만드는 데 중점을 두었습니다.

Problem

오래된 GUI

기존 GUI 스타일로 인해 제품의 완성도가 낮아 보이는 문제

Problem

복잡한 정보 구조

다양한 기능에 비해 정보 구조가 직관적으로 구성되지 않음

Problem

일관되지 않은 UI

기능마다 다른 UI 패턴으로 인해 사용성이 떨어지는 문제

My Role

UX / UI / GUI

GUI 컨셉, 화면 구조, 인터랙션, 디자인 시스템 및 GUI 디자인 설계

Concept Exploration

다양한 디스플레이 환경을 고려한 GUI 컨셉을 탐색했습니다.

4.3인치와 5인치 디스플레이 환경에 맞춰 서로 다른 사용자 경험과 시각적 표현 방식을 중심으로 다양한 GUI 방향성을 제안했습니다.

01. Concept · 4.3inch

시간대에 따라 배경 색상과 인사 문구가 바뀌고, 시침과 분침을 시각화한 그래픽으로 시간을 직관적으로 인식할 수 있도록 디자인했습니다.

02. Concept · 4.3inch

랜덤 배경 이미지를 적용해 매번 다른 분위기와 감성을 제공하고, 중앙에는 반투명 메뉴 박스를 배치해 가독성을 높였습니다.

03. Concept · 5inch

시간의 흐름을 그래픽으로 표현한 GUI 컨셉입니다. 시침과 분을 시각 요소로 재해석해 직관적인 시간 인식을 제공하고, 원형 UI를 적용해 주요 기능의 통일성과 사용성을 강화했습니다.

04. Final Concept · 5inch

GUI와 제품 라이팅을 하나의 인터랙션으로 연결한 최종 컨셉입니다.
화면에서 선택한 기능이 제품 하단 라이팅에도 동일하게 반영되어, 디지털 인터페이스와 물리적 제품이 하나의 사용자 경험으로 이어지도록 설계했습니다.

Final UI

기능과 상태를 직관적으로 전달하는 Smart Home GUI

주요 기능을 카드 형태로 구성하고, 선택한 기능은 컬러와 라이팅 효과로 즉시 피드백을 제공합니다.
현재 활성 상태를 한눈에 인지할 수 있도록 GUI와 제품 인터랙션을 함께 설계했습니다.

01. 5inch GUI

5인치 디스플레이에서는 주요 기능을 카드 형태로 구성하여 현재 선택 상태를 직관적으로 인지할 수 있도록 설계했습니다.

02. GUI Interaction

GUI & Product Interaction

GUI와 제품 라이팅을 하나의 인터랙션으로 연결하여 사용자가 선택한 기능과 제품의 상태를 동시에 인지할 수 있도록 설계했습니다.

01. Menu Selection

GUI에서 기능을 선택

02. Function Interaction

선택한 기능을 실행

03. GUI & Lighting Sync

선택한 기능이 제품 라이팅에 실시간으로 동일하게 반영

03. Final UI · 4.3inch

4.3인치 디스플레이는 주요 기능을 위젯과 풀스크린 인터랙션으로 구성하여 정보를 빠르게 확인하고 기능 실행 결과를 직관적으로 전달하도록 설계했습니다.

GUI Interaction

Outcome

서로 다른 디스플레이 환경에서도 일관된 사용자 경험을 설계했습니다.

5인치와 4.3인치 디스플레이에 최적화된 UX를 설계하여 기능 탐색부터 실행 결과까지 일관된 사용자 경험을 제공했습니다.
GUI와 제품 라이팅을 하나의 인터랙션으로 연결해 사용자가 현재 상태와 실행 결과를 직관적으로 인지할 수 있도록 설계했습니다.
