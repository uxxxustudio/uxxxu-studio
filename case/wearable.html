02 / Project

AI 기반 웨어러블과 모바일 서비스를 디자인했습니다.

시각·청각장애인의 주변 상황 인지와 의사소통을 지원하는 AI 스마트 글래스 및 모바일 애플리케이션의 UX/UI를 설계했습니다.

03 / Problem Solving

시작되지 않은 프로젝트의 UX/UI 구조를 정의하고 초기 디자인 단계까지 구체화했습니다.

프로젝트 초기 단계에서 사용자 흐름과 화면 구조가 구체적으로 정의되지 않은 상태였습니다.
서비스의 주요 기능과 사용 시나리오를 정리하고, 와이어프레임을 고도화한 뒤 주요 화면의 초기 UI 디자인까지 진행했습니다.

01 · Problem

정의되지 않은 UX 구조

사용자에게 제공할 주요 기능과 화면의 관계가 구체적으로 정리되지 않아, 서비스 흐름과 화면 구조를 먼저 정의할 필요가 있었습니다.

02 · Design Decision

사용자 흐름 구체화

주요 사용 시나리오와 기능을 기준으로 화면의 역할과 사용자 흐름을 정리하고, 기존 와이어프레임을 보다 구체적인 구조로 발전시켰습니다.

03 · Solution

초기 UI 디자인으로 확장

고도화된 와이어프레임을 기반으로 주요 화면의 UI와 비주얼 방향을 구체화하여 초기 디자인 단계까지 진행했습니다.

Project Scope

UX/UI 초기 설계

프로젝트의 UX 구조 정의부터 와이어프레임 고도화와 주요 화면의 초기 UI 디자인까지 담당했습니다.

04 / Research

접근성과 웨어러블 서비스의 주요 사례를 조사했습니다.

국내외 접근성 서비스와 AI 기반 보조 서비스의 UI 구성 및 주요 기능을 조사하고, 프로젝트에 적용할 수 있는 디자인 방향을 정리했습니다.

05 / Information Architecture

서비스 구조와 화면의 관계를 설계했습니다.

사용자 요구사항과 주요 기능을 바탕으로 서비스 구조와 화면 계층을 정의하고 Information Architecture를 설계했습니다.

주요 기능과 화면을 구체적인 UX로 설계했습니다.
